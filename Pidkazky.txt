Щоб запустити для домашньої мережі:

На комп’ютері зупиніть npm run dev у його вікні термінала клавішами Ctrl+C.
У PowerShell у папці D:\repos\MovieHubLocal виконайте:

npm run build
npm start

Залиште це вікно відкритим — воно запускає сервер.
На комп’ютері відкрийте в налаштуваннях MovieHub показану HTTPS-адресу.
Зараз це https://192.168.1.6:4175, але IP може змінитися.

Щоб браузер Android не попереджав про недовірений сертифікат, завантажте сертифікат у налаштуваннях MovieHub на комп’ютері, перенесіть на пристрій і встановіть як довірений сертифікат. Не обходьте попередження браузера без встановлення сертифіката. На деяких Android TV встановити власний сертифікат неможливо; тоді їхній браузер може бути несумісним із цим способом доступу.
Під’єднайте телефон/TV до тієї самої Wi‑Fi мережі, відкрийте HTTPS-адресу та введіть одноразовий код зі сторінки налаштувань.
